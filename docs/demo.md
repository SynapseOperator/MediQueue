# 90 秒体验：预约到模拟退款

![患者预约、模拟付款、取消与管理员退款处理](images/demo.gif)

这段 GIF 由 2026-11-17 的 **12 张真实浏览器操作步骤截图**组成，阅读时长 90 秒；它是步骤节选，不是连续录屏，也没有生成或伪造支付页面。画面仅含合成资料，所有金额均为模拟，无实际扣款。

流程：浏览医生与号源 → 确认预约 → 待支付 → 模拟支付成功 → 患者取消 → 待退款 → 管理员模拟退款失败 → 原退款重试成功。录制场景为预约 17、号源 13，页面实际显示 `PENDING_PAYMENT → CONFIRMED/PAID → CANCELLED/REFUND_PENDING → FAILED → SUCCEEDED/REFUNDED`；取消后的预约始终保持取消，未因退款失败恢复。

每帧的说明、展示时长和原截图 SHA-256 见 [步骤记录](images/demo-steps.json)。截图只加了说明栏与等比例排版，第一帧移除了捕获区域的空白边缘。它证明的是该次人工流程；并发正确性由 [独立进程 MySQL 测试](design/concurrency.md#几个真实竞态)证明。

要自己操作，请按 [快速开始](../README.md#快速开始)启动独立演示环境。首次启动会在你的终端显示本次生成的随机账户；本仓库和 GIF 不提供共享固定密码。
