## 测试覆盖的边界

- 7 个模拟配置用例：默认关闭、允许环境显式启用、生产与未识别环境拒绝启用。
- 4 个 HTTP 用例：首页阶段/模拟标识、存活、真实数据库就绪、错误响应不泄露内部信息。
- 2 个 MySQL 基础用例：8.x、InnoDB、utf8mb4、UTC、READ COMMITTED、外键开启与 migration 回滚重建。
- 5 个完整性用例：Unicode/DECIMAL 往返、FK 1452、CHECK 3819、RESTRICT 1451、异常导致相关写入全部回滚。
- 1 个数据库权限用例：运行账号可读 sessions，CREATE 被 1142 拒绝。

所有 fixture 仅位于专用 `mediqueue_test`，DDL 前核验实际库名。未用 SQLite、顺序请求或页面效果替代业务一致性验收。健康失败分支使用合成异常，其余数据库能力检查连接真实 MySQL。

首次健康错误分支测试因 Laravel 测试响应解析 session 而失败；将该错误分支的测试 session 隔离为 array 后重新运行全套通过。Pint 纠正了一处 import 顺序。这些修复未删除检查或放宽 MySQL 约束。
