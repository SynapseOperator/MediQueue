- 医生桌面和 390px 工作台可读并显示本人停诊/开放排班。四种登录状态均曾访问：访客、合成患者、医生、管理员。首次验收结束时各账号已退出并恢复桌面首页；随后为只读展开管理表单重新登录管理员，按负责人要求停止 UI 后该管理员会话仍处于登录状态。

- 本轮未逐项在浏览器构造无医生、售罄、过期、停诊付款资格和错误回显状态；相应自动化测试是否覆盖应以实际测试结果为准。本轮未独立运行共享测试库，也不能用本记录代替 CI 或完整无障碍审计。
